# Alzheimer's Disease Classification

## Project Description:
This Machine Learning model classifies Alzheimer's Disease MRI scans using a Convolutional Neural Network (CNN) architecture. The model helps to identify whether a given MRI scan shows signs of Alzheimer's Disease, which is crucial for early diagnosis and medical purposes.

## Requirements:
- Python 3.12.0
- TensorFlow/Keras
- NumPy
- Pandas
- Matplotlib (for plotting and visualization)
